# 圣兽之王 / Unicorn Overlord

17 character animation packages downloaded from the official public character pages on 2026-10-20. Each ZIP preserves its character directory with the original transparent animated WebP, full-canvas PNG frames, a derived 10-column atlas, and source/timing manifests. There are 1,107 source frames in total (Scarlett 60; the other 16 characters 1,047).

## Data notes

Frame order and duration are decoded from the original WebP. PNG sequences and atlas layout are deterministic local derivatives, not an official accompanying JSON format. All extracted PNG pixels and atlas cells were checked against decoded source RGBA frames. These are official battle-showcase animations, not verified idle animations or a complete nine-state pet.

Only the requested Unicorn Overlord collection is included. Workbench code, runtime data, credentials and unrelated uploaded assets are excluded.
